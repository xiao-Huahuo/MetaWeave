# Agent 知识链接按需挂载验收

本次保留现有文件链接块，扩展其他库形态，并将来源引用与知识块挂载分开。

## 用户要求与实现、验收对应

| 用户要求 | 实现位置 | 实际验收 |
| --- | --- | --- |
| 搜索不自动挂载全部结果 | `MessageList.vue` 移除按 K 编号挂载结果的路径；搜索工具返回选择说明 | 修改前回归失败；修改后仅 K 引用的真实界面没有文件块或原生知识块 |
| 统一 `get_knowledge_url` 获取四库任何知识形态的链接 | `tools/builtin/knowledge.py`、工具定义、`UnifiedSearchService.resolve_knowledge`、正式 `/knowledge/resolve` | 真实 CRUD 创建文件、图书、集锦、组件和文献；经 Vite 开发代理请求五个链接均 200，返回正式原生 DTO |
| 现有第二种文件链接块保持不变 | 保留 `MarkdownContent.vue` 的文件块构造及全部专属样式，统一 URL 工具保留 raw 文件路径 | 既有编码文件块冒烟通过，图标、名称、大小、创建时间和四个状态保持；Agent 页面进入侧栏，紧凑模式进入主编辑区 |
| 其他形态直接复用搜索页组件 | `AgentKnowledgeLinkBlocks.vue` 在显式链接位置挂载 `SearchNativeResultCard` | 实际图书、集锦、组件、文献块可见且分别打开原生侧栏；未改写这些卡片的展示结构 |
| Agent 能主动、单独挂载知识形态块 | 主系统提示词、实际 `ContextBuilder` 注入、搜索工具说明均说明先取 URL，再单独成段输出链接 | 8 项提示词回归；链接缺省、仅 K 编号、仅调用 URL 工具均不触发挂载 |
| 提示词和 README 覆盖所有 Agent 链接类型 | 主提示词、实时注入、README 5.5 | 集中覆盖 Markdown 本地/网页链接、图片、知识块、K/N/A/数字来源编号及可识别文件名入口 |
| 不破坏现有引用、图片和普通链接 | 链接识别只接受应用自己的 `/knowledge/resolve`，文件独立走旧路径 | Markdown、四库 K 引用侧栏、图片预览、危险 URL 清洗与历史附件回归通过 |

## 补充正确性检查

- 桌面 HTTP 和打包 `file://` 场景的相对工具 URL 均以正式后端 URL 为基址；外部同路径 URL 不被当作知识块。
- 参数保留中文、空格、`#`、`&` 和文献 `form_id:row_id`。解析使用当前用户身份，原库归属由正式后端校验。
- 非文件链接保留所属库；原生收藏、隐私及图片封面使用原库。打开历史对象前通过现有设置接口切回所属库，清理相对路径缓存；未保存文件、无权访问、失败和并发切库均有回归保护。
- 缺失对象返回 404、外库访问返回 403。解析失败保留原链接并给出访问失败提示；过期异步响应不得挂载到已修改的回答。
- Markdown 的样式、图片预览、文件名自动链接和代码复制不侵入原生卡片。实际封面加载成功，保留原生 `max-height: 520px` 和圆角；点击封面只打开原生入口。
