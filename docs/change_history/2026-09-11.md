## OCR/VLM 表单与模型预设协调

- OCR/VLM 表单改为与 LLM 设置一致的查看、编辑、保存、取消和 Key 显示交互，统一输入高度、左侧内边距、字体、hover/focus 动效与只读状态；移除导致文字贴边的局部宽泛输入覆盖。
- 新增用户级 MinerU 模型配置预设表、Alembic `20260911_0017`、SettingsService、REST、gRPC 和前端 API，可保存、加载和删除 Key、模型及全部精准 API 限制参数；加载预设不自动改变 VLM/OCR 总开关。
- 新增共享 `SavedModelConfigRow`，LLM 与 VLM 的已保存配置共同复用图书馆条形模式的视觉锚点、主信息列和右侧操作轨道，并适配移动端动作换行。
- 修复预设接口不可用时整个 VLM 表单被 `Promise.all` 阻断的问题：主配置入口先独立渲染，预设失败只降级为空列表。该入口定向 Vitest 1 项通过；未运行全量测试或界面冒烟。
