## 桌面身份桥与固定期限自动登录

- Electron 主进程通过 safeStorage 加密 30 天设备凭据和既有 Fernet 派生密钥，把密文写入正式 AuthDevice 后端接口；主密码不持久化，私有凭据和密钥不经过 renderer。过期只恢复用户名，必须输入密码并点击确定才能重新签发；正常自动登录不修改期限。
- 身份与配置进度 IPC 校验所属应用窗口、顶层 frame、本机 origin 及正式入口路径 `/`、`/index.html`，保留 query/hash 浮窗入口，拒绝同源业务 HTML；异步结束再次检查入口，会话广播与代理 Bearer 注入沿用该判断。悬浮窗只读取公开会话。显式退出立即清理窗口状态与 HttpOnly cookie，并撤销设备及所有关联会话；HTTP 后端离线时调用同一 AuthService 的本机撤销命令。关闭应用保留加密记忆。
- 受管 dev:electron 启动命令统一启动、监督和关闭 Python、Vite、Electron，向 Python 与 Electron 传递同一每次启动 nonce，并将后端 URL 的 HTTP 地址/端口同步到 AgentConfig、将实际 Vite origin 同步到 Cookie/CORS 校验；打包主进程同步 nonce 到内置后端。既有 electron/**/* 打包规则覆盖新增身份模块，无新加密依赖。
- build 入口将类型检查与前端构建改为串行执行，保留原任务和参数转发语义，遵守单批验证内存约束。
- 正式版后端自启动与离线撤销复用同一环境构造，按桌面 API URL 同步 HTTP 地址、端口和后端自身可信 origin，保留 Windows 原生环境。已有服务须通过本次 nonce 的私有随机设备探针才能复用；授权或版本不符会明确拒绝接管。
- 应用会话 cookie 限本机后端目标 origin；受信任的 Vite 相对资源代理附加公开会话 Bearer，以保留封面、背景、预览及附件加载。
