## 语义图谱节点操作与多层关系

- Canvas 语义节点新增与文件树一致的右键菜单：实体提供详情、复制名称、删除；文档提供详情、打开、复制名称、清空节点。
- 详情复用图谱节点侧栏，文档打开复用工作区编辑器侧栏；实体删除和文档清空均通过正式 REST API 持久化，并在完成后刷新图谱。
- 文档清空保留文档本身，删除该文档贡献的点边并仅清理孤立实体，避免误删其他文档仍引用的融合节点。
- 抽取提示明确要求实体—实体多跳关系；写入时文档仅连接关系链根实体，使二层及更深实体由实体关系边形成，同时保留规范化名称融合。
- `GraphPane.vue` 的原节点详情栏拆为独立组件，主组件降至 884 行且视觉行为不变。
- 后端图谱服务 22 项和 REST 2 项、前端组件 3 项和 API 2 项、Chromium 实际交互 1 项均通过；定向 ESLint 0 错误，Vite 生产构建通过。
