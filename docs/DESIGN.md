# MetaWeave(元织) 前端UI/UX设计规范


## 工作区与内容呈现

MetaWeave 使用桌面工作台布局：左侧活动栏负责切换文件、资料库、图谱和其他业务页面，中间区域承载编辑器或当前主页面，左右侧栏用于文件树、Git、TODO 和 Agent。侧栏可折叠并通过分隔条调整尺寸。

## 编辑器与多模态预览

编辑器根据文件类型显示对应模式：

- Markdown：Edit、Preview、Split。
- 纯文本与代码：Text 或 Code。
- CSV：Text 与 Forms；XLS/XLSX：Forms。
- DOCX、PDF 和图片：原件预览与 Markdown 中间层；PPTX 当前以 Markdown 中间层为主，原件预览留空。
- 无法预览的二进制文件：Binary 状态。

Markdown 分栏模式同步编辑区与预览区的滚动位置。全局图片预览使用毛玻璃浮层，支持前后切换、滚轮缩放和拖拽平移，可从 Markdown、Word 预览及 Agent 对话中打开。

## Markdown-to-HTML 交互

文件右键菜单和独立 MD-HTML 页面均可发起 HTML 可视化。界面提供“原结构”和“AI 提炼”两种模式，以及强动效、阴影、圆角、emoji 等生成选项；任务执行时展示进度，完成后可以保存到知识库或系统目录。

## 业务页面设计

- 图书馆使用图书卡片和集锦层级组织资料。
- 组件库使用自适应瀑布流卡片，卡片内保留真实交互，详情页并列展示实时预览和源码。
- 智能表格采用电子表格式编辑，支持拖动行列、调整尺寸、范围选择和右键菜单。
- 密码库采用表格、筛选面板和条目编辑器组合，敏感字段默认隐藏。
- 任务队列采用“等待认领—处理中—等待确认”三栏看板，并以历史页面展示已确认和已终止任务。

## 图谱交互

知识图谱使用 D3 力导向 Canvas。不同图谱通过节点颜色、形状和边的类型区分对象与关系；工具栏提供图谱模式、标签显示、适应画布、刷新、去重和定格操作。节点侧栏负责搜索、展示选中节点和关联节点，打开节点时跳转到对应文档。

## Agent 状态呈现

Agent 对话以流式消息呈现思考、工具调用、任务列表、环境变更和引用来源。子 Agent 的创建、运行、完成、失败、停止和上下文更新显示为可展开事件，侧栏按目标聚合任务卡片。观测页面以卡片、图表和明细列表展示 AgenticRAG、Token、耗时与上下文信息。
